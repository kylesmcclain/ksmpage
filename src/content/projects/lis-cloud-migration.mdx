## What was actually wrong

The failure mode was not subtle. A single-board computer with no redundancy, no managed backup,
and no meaningful access control sat on the critical path between laboratory instruments and the
outside world. Every result for a high-volume assay programme crossed it. If the SD card failed on
a Tuesday, the lab would have lost both its result pipeline and its record of what had already been
reported.

It had also grown organically, which meant nobody could hand an auditor a diagram of it.

## Approach

The migration was sequenced so that at no point did the lab depend on something untested.

**Rebuild rather than lift-and-shift.** The legacy system was not worth carrying forward as-is.
The platform was rebuilt on managed Google Cloud infrastructure with a PostgreSQL backend and a
GitLab-based deployment path, so that future changes had a repeatable route to production instead
of being applied by hand.

**Preserve the edges.** The two integration boundaries — on-premises PCR instrumentation on one
side, external healthcare portal interfaces on the other — were treated as fixed contracts. The
platform underneath them changed completely; what they saw did not.

**Compliance as an architecture input.** Access control, backup policy, and data handling were
specified before the cutover rather than validated after it. HIPAA obligations shaped the IAM
model and the backup posture directly.

**Partnered delivery.** The replacement LIS/LIMS was built, tested, and deployed alongside the
software team. Infrastructure ownership stayed with me; application logic stayed with them; the
integration surface was agreed rather than assumed.

## Result

Clinical result processing runs on resilient managed infrastructure at 99.9% uptime. High-volume
infectious-disease assay results flow end to end without manual intervention, and the instrument
and portal integrations that the lab's throughput depends on were never interrupted.

The environment is now documentable, which — in a regulated setting — is most of the point.
